# EPGDeck (Svelte 5 版) 画面変更仕様書

本ドキュメントは、[EPGStation 画面仕様書 (オリジナル)](./epgstation_ui_spec.md) をベースとして、2026 年のモダン Web 技術（Svelte 5 + Vite 6 + Tailwind CSS v4）への移行、および **15,000 件以上の録画アーカイブ運用** を想定した UI/UX の最適化・統廃合・新機能仕様をまとめた変更設計書です。

---

## 1. 刷新の基本方針と設計思想

1. **仮想 DOM レスによる圧倒的な軽快性 (Svelte 5 Runes)**:
   - 従来の Vue 2 (仮想 DOM + 重厚な Vuetify) から Svelte 5 のネイティブ DOM コンパイルへ移行。
   - CSS サイズを **約 96% 削減 (1.1 MB ➔ 61 kB)**、JS バンドルを **約 76% 削減** し、モバイルや低スペック端末でも極めて高速に動作。
2. **15,000件超の録画アーカイブ特化**:
   - 従来のページ番号移動だけでは困難だった過去データへのアクセスを、**「年・月セレクター（年月ジャンプ）」** と **「ジャンルチップ絞り込み」** で瞬時に検索・閲覧可能に。
3. **動画再生アプリとしての導線強化**:
   - 目的である「番組を見る・再生する」を最優先とし、各画面で **ワンクリックで即座に再生できる目立つ導線（鮮やかな再生ボタン・サムネイルオーバーレイ）** を配置。
   - プレイヤー自体も映像鑑賞に最適な **シャープな四角（直角デザイン / `rounded-none`）** を採用。
4. **デザインシステム（デザイントークン）の完全統一**:
   - 全画面の垂直コンポーネント間余白を **`space-y-5` (20px)**、ヘッダーカードを **`p-4 sm:p-5`** に統一し、一貫性のあるリズム感と視認性を実現。

## 3. 各画面の詳細仕様

### 3.1 ダッシュボード (`/`)
- **録画中番組の最優先アラート**:
  - 録画が進行している場合、最上部にパルスアニメーション付きの「🔴 現在録画中」セクションを表示。
  - 各録画中番組に **「▶ 視聴する」** ボタンを配置し、追っかけ再生・ライブ視聴へ即座に誘導。
- **2 カラムサマリー**:
  - 「直近の予約」（競合警告・重複スキップバッジ付き）
  - 「最新の録画済み」（**「▶ 再生」** ボタン付き）

### 3.2 放映中 (`/onair`)
- **テーブル一覧スタイル**:
  - カラム構成: `['放送局 / 時間', '視聴', '現在の番組', '次の番組']`。
  - 放送時間直下に視覚的な進行バーを配置（% テキストは省きスッキリ表示）。
  - 現在番組・次番組をクリックで「番組詳細ポップアップ」を展開（ワンクリック予約やルール作成へ遷移）。
- **配信設定モーダル**:
  - 「視聴」ボタン押下時にモーダルが展開（ストリーム形式 `HLS`, `MP4`, `WebM` と画質選択）。

### 3.3 番組表 (`/guide`)
- **コンパクトなチャンネル列幅**:
  - `w-40`（160px、従来の約 70%）に最適化し、1画面で多数の放送波・チャンネルを同時に俯瞰。
- **タイトル ＆ 概要の最大化**:
  - 各セル内の開始時間表示を削除し、短時間の番組でもタイトルや概要文が最上段からしっかり読めるレイアウト。
- **鮮明なダークモードジャンルカラー**:
  - 黒背景に沈まない高輝度ボーダー（`-400`系）と 80% リッチティント背景（`dark:bg-*-950/80`）でスタイリッシュに発色。

### 3.4 予約一覧 (`/reserves`)
- **キャンセル・スキップ管理**:
  - 手動予約は「キャンセル（予約取消）」、ルール予約は「キャンセル（重複スキップ）」として即時反映。
  - スキップ中の番組には「復活（スキップ解除）」ボタンを配置。
  - 行クリックで詳細ポップアップが開き、番組情報や保存先、エンコード指定を確認・操作可能。

### 3.5 ルール管理 (`/rule`)
- **実予約数の集計バッジ表示**:
  - `/api/reserves` から各ルールの実予約数を取得し、`4 件` などの青色バッジで表示。
- **詳細ルール作成・編集モーダル (`RuleEditModal.svelte`)**:
  - 検索条件（キーワード、あいまい検索、正規表現、ジャンル、放送波、放送局選択、曜日・時間帯、番組長）。
  - 保存先設定（保存先ストレージ、サブディレクトリ、ファイル名フォーマット）。
  - エンコード設定（第1・第2エンコードプリセット、保存先、元ファイル自動削除）。

### 3.6 録画済み一覧 (`/recorded`) ＆ 録画詳細 (`/recorded/detail`)
- **15,000件最適化**:
  - 年月セレクター（`2026年` × `8月` など）とジャンルチップ絞り込み。
- **録画詳細画面**:
  - サムネイル画像表示（`/api/thumbnails/:id`）、録画ファイルサイズ、保護トグル、エンコード追加モーダル。

### 3.7 統合動画プレーヤー (`Watch.svelte` / `VideoPlayer.svelte`)
- **四角（直角）デザイン (`rounded-none`)**:
  - 余計な角丸を排し、映像鑑賞に最適なシャープな直角スクリーン。
- **HLS キープアライブ ＆ 自動チューナー解放**:
  - 10秒ごとのキープアライブ Ping と、画面離脱・ストリーム終了時の自動 DELETE によるチューナーの即時解放。

## 4. データ・状態管理アーキテクチャ

- **共通ストア (`client/src/lib/stores/`)**:
  - `channels.svelte.ts`: 放送局マスターキャッシュ（`channelId ➔ 局名/放送波` マッピング）
  - `playerState.svelte.ts`: 視聴レジューム再生位置の自動保存・復元
  - `snackbar.svelte.ts`: グローバルトースト通知
  - `theme.svelte.ts`: ダーク/ライトテーマ切り替え
  - `router.svelte.ts`: Svelte 5 Native Reactive SPA Router（HTML5 History モード完全連動）
