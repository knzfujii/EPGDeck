## 1. 全体共通仕様・レイアウト

### 1.1 画面構造
- **ヘッダー（タイトルバー）**:
  - 左側: ハンバーガーメニューボタン（モバイル用ドロワー開閉）、現在の画面タイトル
  - 右側: 画面ごとのコンテキストメニュー（検索、一括編集、ソート、設定等）
- **ナビゲーションドロワー（サイドバー）**:
  - メニュー項目: ダッシュボード、放映中、番組表、予約、録画中、録画済み、エンコード、検索、ルール、ストレージ、設定
- **通知（Snackbar）**:
  - 画面下部に成功（緑）、エラー（赤）、警告（黄）のメッセージをトースト表示
- **リアルタイム更新 (Socket.IO)**:
  - 録画開始/終了、予約追加/更新/削除、エンコード進行状況などのイベントを受信して画面を自動更新

## 2. ダッシュボード (`/`)

### 概要
システムの全体状況（録画中、直近の録画済み、直近の予約）を 3 カラムのパネルで一覧表示するホーム画面。

### 表示項目
- **録画中パネル (`recording`)**:
  - 現在録画中の番組一覧（放送局名、番組名、放送日時、エンコード状態）
  - 「more」ボタン（録画中件数が表示件数を超える場合）
- **録画済みパネル (`recorded`)**:
  - 最新の録画完了番組一覧（サムネイル、番組名、放送局名、ドロップ数、ファイルサイズ、時間）
  - 「more」ボタン（全件一覧へ遷移）
- **予約パネル (`reserve`)**:
  - 直近の録画予約一覧（放送局名、番組名、日時、チューナー競合バッジ、重複スキップ表示）
  - チューナー競合発生時はヘッダーに赤バッジで競合件数を表示
  - 「more」ボタン（予約一覧へ遷移）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 録画中アイテムクリック | アイテムタップ | - | `/recorded/detail/:id`（録画詳細）へ遷移 |
| 録画済みアイテムクリック | アイテムタップ | - | `/recorded/detail/:id`（録画詳細）へ遷移 |
| 予約アイテムクリック | アイテムタップ | - | 番組詳細ダイアログを表示（予約編集・解除が可能） |
| 競合バッジクリック | バッジタップ | - | `/reserves?isConflict=true`（競合予約一覧）へ遷移 |
| 「more」クリック | ボタン押下 | - | 各一覧画面（`/recording`, `/recorded`, `/reserves`）へ遷移 |

## 3. 放映中 (`/onair`)

### 概要
現在放送中のテレビ番組を全局リアルタイムに把握し、ライブストリーミングを開始するための画面。

### 表示項目
- **放送波タブ（設定により切り替え）**: すべて / 地デジ (GR) / BS / CS / SKY
- **チャンネルカード一覧**:
  - 放送局名、チャンネル番号、ロゴ
  - 現在放送中の番組タイトル、放送時間、概要
  - 進行状況プログレスバー（経過時間 / 総時間）
  - 次の放送予定番組（開始時刻、番組名）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 番組カードクリック | カードタップ | - | **配信設定ダイアログ (`OnAirSelectStream`)** を開く |
| 番組表ボタン | アイコン押下 | - | `/guide?channelId=:id`（単局番組表）へ遷移 |
| ストリーム選択 & 再生 | ダイアログ内ボタン | `GET /api/streams/live/:channelId/:type?mode=:mode` | `/onair/watch`（ライブ視聴画面）へ遷移して再生開始 |

---

## 4. ライブ視聴 (`/onair/watch`)

### 概要
放送中のテレビ番組をブラウザ上で低遅延・高画質にリアルタイム視聴する画面。

### 表示項目
- ビデオプレーヤー（HLS.js / MPEGTS.js / ネイティブ HTML5 Video）
- 番組情報カード（放送局名、番組名、概要、詳細情報、ジャンル、放送時間）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 画面マウント | ページ表示 | `GET /api/streams/live/:channelId/hls?mode=:mode` | ストリームIDを取得し再生開始。10秒毎に `PUT /api/streams/:streamId/keep` 送信 |
| 戻る / 離脱 | 戻るボタン/遷移 | `DELETE /api/streams/:streamId` | ストリームを即時停止しチューナープロセスを解放 |

## 5. 番組表 (`/guide`)

### 概要
全チャンネルのタイムライン（EPG）をグリッド形式で俯瞰し、番組予約や番組検索を行う画面。

### 表示項目
- **局ヘッダー (固定)**: チャンネル名、アイコン、クリックで単局表示切り替え
- **時間軸 (固定)**: 0時〜23時（24時間表示、4時起点）
- **番組セル**:
  - タイトル、放送時刻、ジャンル別カラーバー/背景
  - 予約済みマーク（赤帯 / アイコン）
- **メニュー**: 日付セレクター（今日〜8日後）、放送波切り替え、ジャンル強調表示設定、表示サイズ変更

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 番組セルクリック | セルタップ | `GET /api/schedules/detail/:programId` | **番組詳細ダイアログ (`ProgramDialog`)** を表示 |
| 予約追加 | ダイアログ内ボタン | `POST /api/reserves` | 予約を登録し、セルに予約マークを即時反映 |
| 予約解除 | ダイアログ内ボタン | `DELETE /api/reserves/:reserveId` | 予約を取り消し、セルの予約マークを消去 |
| 日付選択 | 日付ダイアログ | `GET /api/schedules?startAt=...&endAt=...` | 指定日のタイムラインへスクロール・再描画 |
| 局ヘッダー押下 | 局名タップ | - | `/guide?channelId=:id`（指定局の1週間番組表）へ切り替え |

## 7. 予約一覧 (`/reserves`)

### 概要
登録されている録画予約の確認、チューナー競合の解消、重複スキップの管理を行う画面。

### 表示項目
- 予約一覧（放送日時、放送局、番組名、概要、録画モード、状態）
- **状態バッジ**:
  - **競合 (isConflict)**: チューナー不足による録画失敗警告（赤色）
  - **重複 (isOverlap)**: すでに同一番組が録画済みのためスキップ（グレー）
  - **正常予約**: 通常の録画待機（緑/青）
- 一括編集モード（複数選択削除）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 予約削除 | ゴミ箱アイコン | `DELETE /api/reserves/:id` | 予約を取り消し、一覧から即時除外 |
| 一括削除 | 複数選択後削除 | `POST /api/reserves/delete` | 選択した予約を一括取り消し |
| 手動予約追加 | ヘッダーの「＋」 | - | `/reserves/manual`（時間指定手動予約）へ遷移 |
| 重複手動解除 | 詳細内トグル | `POST /api/reserves` (overlap無視) | 重複スキップを解除し、強制録画予約へ変更 |

### ユーザーアクションと挙動

| :--- | :--- | :--- | :--- |

## 10. 録画済み一覧 (`/recorded`)

### 概要
保存された過去の録画番組（TS / エンコード済み動画）の検索、再生、ダウンロード、一括削除を行う画面。

### 表示項目
- **表示モード**: カード表示 / リスト（テーブル）表示
- **アイテム情報**: サムネイル、番組名、放送局、日時、録画時間、ファイルサイズ、ドロップ数/エラー数、エンコード状態
- **絞り込みメニュー**: キーワード検索、放送局絞り込み、ジャンル絞り込み、ルール絞り込み
- **一括管理**: クリーンアップ（ゴミ箱）、複数選択削除

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 詳細表示 | アイテムタップ | - | `/recorded/detail/:id` へ遷移 |
| 直接再生 | 再生ボタン | - | `/recorded/watch?recordedId=:id` へ遷移 |
| 一括削除 | 複数選択 ➔ 削除 | `POST /api/recorded/delete` | 選択した録画ファイルとDBレコードを一括削除 |
| クリーンアップ | メニュー ➔ 整理 | `POST /api/recorded/cleanup` | 実ファイルが存在しないDBレコードを自動削除 |

## 11. 録画詳細 (`/recorded/detail/:id`)

### 概要
録画番組のメタデータ（詳細説明、出演者、ドロップログ）の閲覧、再生形式の選択、エンコードの指示、Kodi/外部アプリ連携を行う画面。

### 表示項目
- 番組名、放送局、日時、ジャンル、詳細テキスト（出演者・あらすじ）
- ドロップ・エラー情報（クリックで詳細ドロップログダイアログを表示）
- 保持している動画ファイル一覧（TS, MP4, H.264, 720p, 1080p など各ファイルのサイズ）
- サムネイル一覧

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 直接再生 | Playボタン | - | `/recorded/watch?recordedId=:id` でブラウザ再生 |
| ストリーミング再生 | 配信ボタン | `GET /api/streams/recorded/...` | `/recorded/streaming/:id` でトランスコード再生 |
| ファイルダウンロード | ダウンロード | `GET /api/videos/:id` | ブラウザのダウンロード機能で動画ファイルを保存 |
| 追加エンコード | エンコード追加 | `POST /api/recorded/:id/encode` | 指定プリセットでエンコードキューに追加 |
| 外部アプリ起動 | URLスキーム | `vlc://`, `infuse://` 等 | 外部動画プレーヤーアプリを起動してストリーミング |
| 録画削除 | 削除ボタン | `DELETE /api/recorded/:id?isDeleteFile=true` | 録画ファイルとレコードを削除して一覧へ戻る |

## 13. 録画ストリーミング再生 (`/recorded/streaming/:id`)

### 概要

### アクションと挙動

## 16. 番組検索 & ルール追加 (`/search`)

### 概要
キーワード・ジャンル・放送局・時間帯などの条件で番組を検索し、一致する番組を自動録画する「ルール」を作成する画面。

### 表示項目
- 検索フォーム（キーワード、正規表現、除外キーワード、あいまい検索、ジャンル、放送局、曜日、時間帯）
- 検索結果一覧（条件に一致する今後の放送予定番組）
- ルールオプション（録画モード、重複回避、保存先サブディレクトリ、エンコード指定）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 検索実行 | 検索ボタン | `POST /api/schedules/search` | 該当する番組一覧を即時表示 |
| ルール登録 | ルール追加ボタン | `POST /api/rules` | 自動録画ルールを作成し `/rule` へ遷移 |

---

## 17. ルール一覧 & 管理 (`/rule`)

### 概要
登録されている自動録画ルールの一覧確認、有効/無効の切り替え、ルールの編集・削除を行う画面。

### 表示項目
- ルールカード一覧（キーワード、対象局、ジャンル、保存先フォルダ、有効/無効トグル）

### ユーザーアクションと挙動
| アクション | トリガー | 処理 / API 呼び出し | アクション後の動き |
| :--- | :--- | :--- | :--- |
| 有効/無効切替 | スイッチトグル | `PUT /api/rules/:id/enable` or `disable` | ルール状態を更新 |
| ルール編集 | 編集ボタン | - | `/search?ruleId=:id`（検索画面に条件を流し込み）へ遷移 |
| ルール削除 | 削除ボタン | `DELETE /api/rules/:id` | ルールを削除 |

## 19. 設定 (`/settings`)

### 概要
クライアント側の表示挙動、描画パフォーマンス、PWA、URLスキーム、外部連携を設定する画面。

### 表示項目
