# EPGDeck UI/UX 画面仕様書 (UI Specification)

本ドキュメントは、モダン Web 技術（Svelte 5 + Vite + Tailwind CSS v4）を採用し、**10万件規模の録画アーカイブ運用** を想定した EPGDeck の UI/UX 設計・全画面構成・デザインシステム仕様をまとめた技術仕様書です。

---

## 1. 設計思想と基本方針

1. **仮想 DOM レスによる軽快な操作性 (Svelte 5 Runes)**:
   - Svelte 5 ネイティブコンパイルとルート単位のコード分割（Lazy Loading）により、軽量なバンドル構成（CSS 約 61 kB）と低スペック端末でも高速な描画・操作性を実現。
2. **10万件規模の録画アーカイブ最適化**:
   - **「年・月セレクター」** と **「主要ジャンルピル」** により、膨大な録画データへの瞬間ジャンプ・絞り込みを実現。
   - サムネイル階層化（シャーディング）およびドロップ0件ログ自動削除によりファイルシステム負荷を最小化。
3. **動画視聴アプリとしての導線強化**:
   - 各画面からワンクリックで視聴・再生へ移行できる明瞭なアクション配置。
   - プレイヤー自体も映像鑑賞に最適な **直角デザイン (`rounded-none`)** を採用。
4. **デザイントークンとリズムの統一**:
   - 垂直コンポーネント間余白を `flex flex-col gap-4 sm:gap-5`（16px / 20px）、カード内パディングを `p-4 sm:p-5` に統一。
5. **自己説明的なUIと全体の一貫性 (Self-Explanatory & Cohesive UX)**:
   - 機能説明やマニュアルを読まなくても直感的に操作できる自己説明的なUIを目指し、アプリ全体でコンポーネント、操作フィードバック、語彙・表記を統一。
6. **目的別の 3 セクションナビゲーション**:
   - 「視聴・ブラウズ系（ダッシュボード ➔ 録画一覧 ➔ 番組表 ➔ 放送中）」➔「予約・ルール系（予約一覧 ➔ ルール一覧 ➔ 番組検索）」➔「システム系（エンコード一覧 ➔ システムログ）」。

## 3. 各画面の詳細仕様

### 3.1 ダッシュボード (`/`)
- **2 カラム構成**: 左に最新録画、右に直近予約（直近10件制限、総件数はバッジ表示、「すべて」で予約一覧へ遷移）。
- **録画中番組のインライン表示**: 最上部にパルス付き「🔴 録画中」バッジと進行度バーを表示。「▶ 視聴」および「⏹ 停止」（3択モーダル）を直接操作可能。
- **チューナー競合警告**: 競合発生時のみアコーディオン警告（重複スキップは除外）。
- **厳格な録画中判定**: API `/api/recording` を最優先照合し、競合・スキップ・重複枠を確実に除外。

### 3.2 放送中 (`/onair`)
- **3 カラムテーブル構成**: `[放送局]`、`[現在の番組]`、`[次の番組]`。
- **即時アクション**: 「▶ 視聴」、現在番組の「🔴 録画」/「⏹ 停止」（3択モーダル）、次番組の「+ 予約」/「✓ 予約中」。
- **セル全体クリック & ルール作成**: セルクリックで番組詳細モーダルを表示。「この番組でルール作成」から検索ワードと `channelId` を引き継いで `/rule/edit` へ遷移。
- **休止中・サブチャンネル対応**: 未来番組がある場合は現在枠を「放送休止中」と表示し次番組予約を可能化。
- **ツールバー**: 放送波タブ（`FilterTabs`）、残り時間表記、ジャンルピル絞り込み、キーワード検索。

### 3.3 番組表 (`/guide`)
- **全放送波横並びグリッド**: デフォルト「すべて (`all`)」、チャンネル列幅 `w-40`（160px）。
- **ARIB 準拠の日付管理**: 朝 4:00 起点境界（0:00〜3:59 は前日扱い）、最大 8 日間表示、48px 局名ヘッダーオフセット加算。
- **レイアウト最適化**: `h-[calc(100dvh-...)]` によるスクロール破損防止、日付切替時もスクロール位置維持、過去24時間番組保持。
- **UI・視認性**: 時刻列スタック表記、ダークモード用高輝度ジャンルカラー、終了番組ディム表示、現在時刻線、番組詳細から「ルール作成へ」直接遷移。

### 3.4 予約一覧 (`/reserves`)
- **録画中番組の 3 択停止操作 (`RecordingActionModal`)**:
  1. **完了として保存 (`finish`)**: 実尺確定・サムネイル・エンコード・録画履歴（二重録画防止）登録。
  2. **中断して保存 (`stop`)**: ファイル保持・エンコード実行、録画履歴未登録（再放送救済）。
  3. **録画を取り消し (`discard`)**: 即時停止し書き込み途中のファイルを物理削除。
- **タブ & 視認性**: 「すべて ➔ 重複 ➔ スキップ ➔ 競合」。正常予約は白背景＋左ボーダー、状態ごとに明確な色分け。
- **未来予約管理**: 手動予約の取消、ルール予約のスキップ / 復活。
- **共通録画オプション (`RecordingOptionForm`)**: 保存先、エンコード（最大3系統）、元TS削除、末尾欠け許可（`allowEndLack`）。

### 3.5 ルール一覧 (`/rule`) ＆ ルール作成・編集 (`/rule/edit`)
- **優先度（Priority 1〜10）ソート**: 優先度降順 ➔ ID 昇順で調停順序と一致。
- **フィルタ・検索**: キーワード検索、有効 / 無効 / すべて タブ、編集画面との状態同期（`sessionStorage`）。
- **ルール編集 (`/rule/edit`)**:
  - **通常検索 ⇄ 時間指定予約切替**: タイトル・局・曜日・時間帯（日跨ぎ対応）。
  - **未来録画予定プレビュー**: 編集ロード時に自動検索し、ヒット番組の個別スキップ/復活を直接操作。
  - **キーワード自動抽出**: 記号（`[字]`, `【新】` 等）を除去し先頭の有効単語を抽出。

### 3.6 録画一覧 (`/recorded`) ＆ 録画詳細 (`/recorded/detail`)
- **録画一覧 (`/recorded`)**:
  - ツールバー: 年月セレクター、主要ジャンルピル、キーワード検索、表示件数セレクター（10/25/50/100）。
  - 複数選択一括削除（保護番組 `isProtected` は自動除外）。
  - ページャー: 直接ジャンプ（Go）、スマホ時の上部自動スクロール吸着。
  - 状態復帰: 詳細から戻る際に検索条件・年月・ページ位置を自動復元。
- **録画詳細 (`/recorded/detail`)**:
  - **インライン統合プレイヤー**:
    - 詳細上部に 16:9 領域を常設（初期状態はサムネイル＋再生ボタン、自動再生なし）。
    - スクロール時の上部吸着（スティッキー `sticky top-0 z-30`、デフォルト無効）。ヘッダー右端のピン留めボタンでトグル可能（`localStorage` 永続化）。横向き狭小時は自動解除。
    - 再生開始後は動画終了時もプレイヤー領域を維持。番組遷移時は旧ストリーム解放・未再生初期化。Kodi 連携時はインライン再生を自動停止。
  - **サブメニュー (`…`)**: 再生オプション、エンコード追加、ドロップログ、サムネイル再作成（秒数指定）、二重録画防止（履歴）除外/追加、録画削除（赤色分離）。
  - **生成ファイル一覧**: 36px 共通ボタン（再生、Kodi、外部再生、ダウンロード）、削除ボタン前の垂直分離線。
  - **同一ルール動画カルーセル**: 関連番組を横スクロール表示。
  - **ドロップログ可視化**: 映像/音声/字幕/制御情報の種別分類、タイムライン表示、シークバー上のピンマーカー連携。

### 3.7 統合動画プレーヤー (`Watch.svelte` / `VideoPlayer.svelte`)
- **役割分離**: 録画視聴は `/recorded/detail` に統合。`Watch.svelte` は放送中ライブ専用。
- **直角デザイン (`rounded-none`)**: 映像鑑賞に最適なシャープな四角スクリーン。
- **キープアライブ**: 10秒ごとの Ping、画面離脱時の即時ストリーム停止。
- **タッチ操作保護**: 合成 `mousemove` 除外、全面透明オーバーレイによる2段階トグル、非表示時の `inert`。
- **再生開始時クリーンビュー**: 開始時は全コントロール非表示、タップ・ホバー時のみ3.5秒一時表示。
- **シーク & クイック操作**:
  - 中央クイック操作（10s戻し / 30s送り、連打累積表示、280ms デバウンス、透過デザイン）。
  - 画面左右ダブルタップ（左1/3で-10s、右1/3で+30s、OSDアニメーション、中央1/3は操作トグル）。
  - 実録画時間（duration）の3段階フォールバック（API実測 ➔ DB実測 ➔ 予定枠）。

### 3.8 番組検索 (`/search`)
- 条件（キーワード、放送局、ジャンル、時間帯）による未来番組検索。
- 検索結果からワンクリックで `/rule/edit` へ全条件を引き継ぎ遷移。Escape キーによる入力クリア。

## 4. データ・状態管理アーキテクチャ

クライアントの状態管理は Svelte 5 Runes を用いたシングルトンストアクラスとしてカプセル化：
- `channels.svelte.ts`: 放送局マスターキャッシュ
- `playerState.svelte.ts`: レジューム再生位置の永続化
- `snackbar.svelte.ts`: グローバルトースト通知
- `theme.svelte.ts`: ダーク/ライトテーマ切り替え
- `router.svelte.ts`: Native Reactive SPA Router
- `readOnly.svelte.ts`: リードオンリーモード状態と権限管理
- `recordingOptionForm.svelte.ts`: 録画オプションフォーム状態の一元化

## 5. リードオンリーモード（閲覧専用モード）仕様

- **UI 制御**:
  - ヘッダーに「🔒 閲覧専用」「🔓 管理者モード」バッジを表示。
  - 閲覧専用時は削除・予約変更・保護トグル等の破壊的操作ボタンを非表示化。
  - 許可設定（`allowedOperations`）に応じてダッシュボード・検索・ルール一覧等の表示/非表示を動的制御。
- **バックエンド多層防御**:
  - Hono `readOnlyMiddleware` により、未認証の更新系リクエスト（POST, PUT, DELETE, PATCH）および非許可 API を `403 Forbidden` (`readOnlyMode`) で確実に遮断。

## 6. PWA・モバイル最適化・システム連携

- **PWA (Progressive Web Apps)**:
  - 最小構成 Service Worker によりキャッシュ事故（新バージョン不反映・ストリーミング妨害）を防止しつつネイティブ全画面起動を実現。
- **動的ビューポート & セーフエリア**:
  - `h-dvh` と Tailwind v4 セーフエリアユーティリティ（`pb-safe`, `pt-safe`）により iPhone の Home Indicator やノッチとの干渉を防止。
- **外部プレイヤー連携 (URL Scheme)**:
  - スマホ・タブレットの録画詳細画面に「外部再生」ボタンを配置し、VLC 等の外部アプリを URL スキーム / インテントで直接起動。
- **モバイル・タブ復帰時の自動ステータス同期 (`ForegroundRefreshManager`)**:
  - Page Visibility API および `pageshow` を監視し、スリープ復帰時や Socket.IO 再接続時に自動で最新ステータスを再フェッチ。

### 7. コンポーネント・UI スタイル共通化と操作安全設計（デザインシステム）

### 7.1. 共通コンポーネント (`client/src/lib/components/common/`)
- **`Button.svelte` / `IconButton.svelte`**: バリアント（`primary`, `secondary`, `danger`, `danger-outline`, `ghost`）、サイズ（`sm`: 32px, `compact`: 36px, `md`: 40px）。
- **`Divider.svelte`**: 垂直（`vertical` / 22px / 幅1px）および水平（`horizontal` / 幅100% / 高さ1px）の視覚的境界線。
- **`Input.svelte` / `Select.svelte` / `Textarea.svelte` / `Checkbox.svelte`**: 高さ 40px（`h-10`）、フォーカスリング、ダークモード対応。
- **`Card.svelte`**: パディング・枠線・背景・シャドウを統一したコンテナ。
- **`Badge.svelte`**: 放送波、予約種別、ステータス（保護中/録画中/競合/スキップ/重複）バッジ。
- **`SearchInput.svelte`**: 検索アイコン、Escape クリア、44px タッチ領域対応の検索ボックス。
- **`FilterTabs.svelte`**: 横スクロール、アクティブインジケーター、件数バッジ付きタブ。
- **`PageHeader.svelte`**: 画面タイトル・サブタイトル・アクションをまとめた統一ヘッダー。
- **`ReadOnlyGuard.svelte`**: 閲覧専用モード案内カードの一元化。
- **`LoadingState.svelte` / `EmptyState.svelte`**: 読込中および 0 件時の表示レイアウト標準化。

### 7.2. 誤操作防止の安全設計
- **物理的分離 (`Divider vertical`)**: 通常操作ボタンと破壊的操作ボタン（削除・停止等）の間に垂直区切り線を配置。
- **控えめなアウトライン (`variant="danger-outline"`)**: 危険操作はソフトローズ枠線とし、ホバー・フォーカス時に警告赤へ遷移。
- **画面端タッチ保護**: スマホ片手操作時の手のひら誤接触を防ぐため、右端に `pr-5 sm:pr-6` などの安全余白を確保。
- **44px タッチターゲット**: モバイル操作時のタップミスを防ぐため主要ボタンに 44px 以上のタップ領域を確保。

### 7.3. サイズ階層・余白の標準化
- **ツールバー・主要ボタン**: 高さ 40px（`h-10` / `size="md"` / `rounded-xl` / 14px）。
- **一覧行・カード内アクション**: 高さ 36px（`size="compact"` / `rounded-lg` / 12px）。
- **サブタイトル**: `text-xs sm:text-sm text-slate-500`。件数構文は `全 X 件` / `X 件 / 全 Y 件` 等に統一。
- **モバイル下部余白 (`pb-safe-8`)**: `<main>` 下部に 32px + セーフエリア余白を確保しホームバー被りを防止。
- **Flexbox Gap 設計 (`flex flex-col gap-*`)**: マジックナンバーの `calc()` を排し、Flexbox Gap と `min-h-0` による Intrinsic Sizing を徹底。

### 7.4. アクションボタン語彙体系（3大操作パターン）
1. **枠追加（編集画面を開く）**: `[＋] 予約追加`, `[＋] ルール追加`
2. **画面内確定（送信）**: 新規は `登録`、既存変更は `更新`
3. **直接予約（即時ワンタップ実行）**: `録画予約`
4. **体言止め統一**: `ルール編集`, `設定更新`, `視聴`, `保護`, `削除`, `重複判定追加`, `重複判定除外`
